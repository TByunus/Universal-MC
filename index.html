Hazır Skript Kütüphanesi (21 Adet)

Doğrudan sunucunuza ekleyebileceğiniz hazır `.sk` kodları.

1. Hoş Geldin Mesajı .sk
on join:
    send "&aSunucuya Hoş Geldin %player%!" to player
2. İlk Giriş Ödülü .sk
on first join:
    give 1 diamond to player
    broadcast "&e%player% sunucuya ilk kez katıldı!"
3. Sohbet Temizleme .sk
command /cc:
    permission: op
    trigger:
        loop 100 times:
            broadcast ""
        broadcast "&cSohbet yetkili tarafından temizlendi!"
4. Otomatik Duyuru .sk
every 5 minutes:
    broadcast "&b[Duyuru] &fDiscord sunucumuza katılmayı unutmayın!"
5. Gece Atlatıcı .sk
on bed enter:
    execute console command "time set day"
    broadcast "&eBiri yatağa girdi, sabah yapılıyor!"
6. Savaştan Kaçış Takibi .sk
on damage of player:
    set {combat::%victim%} to 10
    set {combat::%attacker%} to 10
7. Giriş Ses Efekti .sk
on join:
    play sound "entity.player.levelup" to player
8. Oyuncu Kafası Alma .sk
command /kafa []:
    trigger:
        give skull of arg-1 to player
9. Ölüm Coin Sistemi .sk
variables:
    {coin::%player%} = 0
on death of player:
    add 1 to {coin::%attacker%}
    send "&aKill aldın! +1 Coin" to attacker
10. Sohbet Kilitleme .sk
command /sohbetkapat:
    permission: op
    trigger:
        set {chat.lock} to true
        broadcast "&cSohbet kapatılmıştır."
11. Rastgele Işınlanma (RTP) .sk
command /rtp:
    trigger:
        set {_x} to random integer from -500 to 500
        set {_z} to random integer from -500 to 500
        teleport player to location({_x}, 70, {_z})
12. Özel Ölüm Mesajı .sk
on death of player:
    set death message to "&c%victim%, %attacker% tarafından yok edildi!"
13. VIP Giriş Duyurusu .sk
on join:
    player has permission "vip.giris":
        broadcast "&6[VIP] %player% oyuna bağlandı!"
14. Küfür Engelleyici .sk
on chat:
    message contains "kötükelime":
        cancel event
        send "&cLütfen sohbet kurallarına uyunuz!"
15. Gece Görüşü Verici .sk
command /nv:
    trigger:
        apply night vision to player for 999 days
16. Can Bilgisi Gösterici .sk
on damage of player:
    send "&aRakibin Kalan Canı: %health of victim%" to attacker
17. Sandık Kitleme (Çubuk ile) .sk
on right click on chest with stick:
    send "&eBu sandık kilitlendi!" to player
18. Süreli Hız Desteği .sk
on join:
    apply speed 1 to player for 10 seconds
19. Çıkış Mesajı .sk
on quit:
    broadcast "&7%player% oyundan ayrıldı."
20. Seviye Ödülü .sk
on level change:
    give 5 emerald to player
    send "&aSeviye atladığın için ödül kazandın!"
21. Otomatik Çöp Kutusu .sk
command /cop:
    trigger:
        open chest with 3 rows named "&cÇöp Kutusu" to player
